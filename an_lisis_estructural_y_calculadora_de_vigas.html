Fundamentos del Análisis Estructural

1. Equilibrio Estático

Para que una viga simplemente apoyada se mantenga en reposo bajo la acción de cargas externas, debe cumplir las ecuaciones fundamentales de la estática en el plano:

$$\sum F_y = 0 \quad \text{y} \quad \sum M_A = 0$$

Esto nos permite despejar las reacciones de soporte en los apoyos $R_A$ (izquierdo) y $R_B$ (derecho).

2. Cortante y Momento Flector

La fuerza cortante $V(x)$ representa la suma algebraica de todas las fuerzas verticales a la izquierda de la sección $x$. El momento flector $M(x)$ es la suma de los momentos resultantes.

$$V(x) = \frac{dM(x)}{dx}, \quad w(x) = -\frac{dV(x)}{dx}$$

El momento flector máximo ocurre exactamente donde la fuerza cortante $V(x)$ cruza por cero.

3. Deflexión y Ecuación de Euler-Bernoulli

La deformación o curva elástica $v(x)$ de la viga bajo flexión depende directamente de la rigidez a la flexión ($EI$), gobernada por la ecuación diferencial:

$$EI \frac{d^2v}{dx^2} = M(x)$$

Donde $E$ es el Módulo de Elasticidad del material y $I$ es el Momento de Inercia de la sección transversal.

beam-solver.js Cálculo de Reacciones y Superposición 
function calculateBeamPhysics(L, P, a, w, E, I) {
    // 1. Reacciones de Apoyo (Superposición de P + w)
    // Para carga puntual P: Ra_p = P * (L - a) / L, Rb_p = P * a / L
    // Para carga uniforme w: Ra_w = w * L / 2, Rb_w = w * L / 2
    const Ra = (P * (L - a) / L) + (w * L / 2);
    const Rb = (P * a / L) + (w * L / 2);

    // 2. Muestreo discreto a lo largo de x [0 -> L]
    const steps = 200;
    const dx = L / steps;
    let points = [];

    for (let i = 0; i <= steps; i++) {
        let x = i * dx;
        
        // Cortante V(x)
        let V = Ra - (w * x) - (x >= a ? P : 0);
        
        // Momento Flector M(x)
        let M = (Ra * x) - (w * x * x / 2) - (x >= a ? P * (x - a) : 0);
        
        points.push({ x, V, M });
    }
    return { Ra, Rb, points };
}
diagram-render.js Trazado Dinámico Vectorial en Canvas 
function drawDiagram(canvas, dataPoints, keyName, colorFill, colorLine) {
    const ctx = canvas.getContext('2d');
    const W = canvas.width;
    const H = canvas.height;
    ctx.clearRect(0, 0, W, H);

    // Escalar valores al alto/ancho del Canvas
    const padding = 20;
    const maxVal = Math.max(...dataPoints.map(p => Math.abs(p[keyName])), 0.1);
    const scaleY = (H / 2 - padding) / maxVal;
    const scaleX = (W - 2 * padding) / dataPoints[dataPoints.length - 1].x;

    // Eje Neutro Center Line
    ctx.beginPath();
    ctx.strokeStyle = '#64748B';
    ctx.moveTo(padding, H / 2);
    ctx.lineTo(W - padding, H / 2);
    ctx.stroke();

    // Relleno Poligonal del Diagrama
    ctx.beginPath();
    ctx.moveTo(padding, H / 2);
    dataPoints.forEach(p => {
        let cx = padding + p.x * scaleX;
        let cy = H / 2 - (p[keyName] * scaleY);
        ctx.lineTo(cx, cy);
    });
    ctx.lineTo(W - padding, H / 2);
    ctx.fillStyle = colorFill;
    ctx.fill();
    ctx.strokeStyle = colorLine;
    ctx.stroke();
}
